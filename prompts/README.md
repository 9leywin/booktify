# Промпты

Четыре промпта конвейера. Каждый — обычный markdown-файл; код читает его целиком, подставляет
`{{переменные}}` и отправляет как `system` / `user` сообщения.

| Файл | Шаг | Когда вызывается | Ответ |
|---|---|---|---|
| `glossary_v1.md` | `profile+glossary` | один раз на книгу, до перевода | JSON: профиль + записи глоссария |
| `translate_v1.md` | `translate` | на каждый фрагмент (~1 300 слов) | JSON: блоки + новые термины + сомнения |
| `review_v1.md` | `review` | на каждый фрагмент, режим «Обычное» и выше | JSON: точечные правки |
| `review_v1.md` (ветка `verify`) | `verify` | на книгу, выборочно | JSON: откатить / оставить |

## Правила версионирования

- Имя файла: `<шаг>_v<N>.md`. Старые версии не удаляем — по ним считался кэш и отчёт.
- Любая правка текста промпта — новая версия, даже если исправлена одна запятая.
  Иначе кэш подмешает переводы, сделанные по другому промпту.
- В отчёт книги попадает версия каждого промпта и модель — чтобы через месяц было понятно,
  чем именно переведена книга.

## Переменные

Общие для всех шагов:

| Переменная | Что это |
|---|---|
| `title`, `author`, `lang` | метаданные книги |
| `genre`, `pov`, `tense`, `tone`, `address`, `notes` | из профиля книги |
| `recap` | 3–5 предложений о том, что было в предыдущих главах |
| `prev_en`, `prev_ru` | последние два абзаца предыдущего фрагмента |
| `glossary` | отфильтрованные записи: только релевантные этому фрагменту + ядро |
| `forbidden` | варианты, которые пользователь запретил |
| `chapter`, `chunk_no`, `chunk_total` | место фрагмента в книге |
| `blocks_html` | блоки в виде `<block id="c07.b012"><p>…</p></block>` |

## Ограничения

- Промпт перевода не должен превышать ~4 000 токенов системной части. Всё, что длиннее,
  модель начинает игнорировать выборочно.
- Глоссарий в запросе — не больше 60 строк. Отбор: точное вхождение `en` в тексте фрагмента
  (по границе слова) + 10–15 «ядерных» записей книги.
- Примеры «плохо → хорошо» в промпте — из реального отчёта по прошлой книге. Это работает
  заметно лучше, чем список запретов.
